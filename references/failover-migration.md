# 失败迁移机制（Failover Migration）

## 概述

失败迁移是路由引擎的最后一道防线。当任务在目标设备上执行失败时，自动按三级策略进行迁移，避免任务彻底卡死。

## 故障检测

### 触发条件

| 故障类型 | 检测方式 | 判定标准 |
|----------|----------|----------|
| 工具调用超时 | 工具返回 timeout | 响应时间 > 30秒 |
| 工具调用报错 | 工具返回 error | 非空 error 字段 |
| 设备离线 | 心跳检测 | 连续2次心跳超时 |
| 子任务失败 | 执行结果检查 | exit_code != 0 或 result=null |

### 故障分级

SEVERITY_LOW = 工具返回警告但仍可用
SEVERITY_MEDIUM = 工具调用失败但设备在线
SEVERITY_HIGH = 设备离线或核心服务不可用

## 三级迁移策略

### Level 1：同设备换工具重试

触发条件：工具调用报错/超时，但设备仍然在线
策略：在同一设备上尝试替代工具

| 失败工具 | 替代工具 | 场景 |
|----------|----------|------|
| web_search 超时 | url_fetch | 搜索挂了，直接抓已知URL |
| write_file 失败 | append_file | 写入失败，尝试追加 |
| read_file 失败 | list_files + read_file | 文件路径不对，先列目录 |
| tool_search 无结果 | 直接 call_tool 已知工具 | 搜索不到，用已有工具 |

重试规则：
- 同一工具最多重试 2 次
- Level 1 最多尝试 3 组替代工具组合
- 全部失败 → 升级到 Level 2

### Level 2：换设备执行

触发条件：Level 1 失败，或设备离线
策略：将任务迁移到另一台可用设备

迁移流程：
1. 检查是否有其他在线设备
2. 对候选设备重新执行路由打分
3. 选择得分最高的设备
4. 在新设备上从失败步骤重新执行
5. 如果新设备也有该工具 → 直接重试
6. 如果新设备没有该工具 → 尝试该设备的替代工具（Level 1 逻辑）
7. Level 1 也失败 → 升级到 Level 3

迁移约束：
- 同一任务最多迁移 2 次（避免无限跳转）
- 迁移时携带之前的执行上下文（已完成的子任务结果）
- 迁移不改变任务内容，只改变执行位置

### Level 3：任务拆分 + 人工兜底

触发条件：Level 2 也失败，或所有设备都无法完成
策略：
1. 能做的部分先做，输出已完成结果
2. 不能做的部分标记为 "pending_human"
3. 给用户明确提示哪些需要手动处理

输出格式：
✅ 已完成：
  - 查询最近短信（由手机 phone-01 执行）
  - 统计短信数量（由手机 phone-01 执行）
❌ 需要手动处理：
  - 将统计结果写入桌面Excel文件
  - 原因：所有设备的文件操作均失败
  - 建议：请在电脑上手动打开Excel并粘贴以下数据

## 迁移决策树

任务执行失败?
├── 设备在线?
│   ├── Level 1: 同设备换工具重试
│   │   ├── 成功 → 结束
│   │   └── 失败 → Level 2
│   └── Level 2: 换设备执行
│       ├── 有其他在线设备?
│       │   ├── 是 → 迁移到新设备
│       │   │   ├── 成功 → 结束
│       │   │   └── 失败 → Level 3
│       │   └── 否 → Level 3
│       └── Level 3: 人工兜底
│           └── 输出已完成部分 + 标注待人工处理
└── 设备离线?
    └── Level 2 → Level 3

## 迁移次数限制

| 级别 | 最大次数 | 超过后 |
|------|----------|--------|
| Level 1 | 3次 | 升级到 Level 2 |
| Level 2 | 2次 | 升级到 Level 3 |
| Level 3 | 1次 | 终止，输出最终状态 |
| 总计 | ≤ 6次 | 强制终止 |

## 高风险操作保护

以下操作不会触发自动迁移重试：
- 涉及支付、扣款的操作
- 涉及删除不可恢复数据的操作
- 涉及账号注销/密码修改的操作

遇到这类操作失败，直接提醒用户手动处理，不做自动迁移。

## 边界

- 迁移过程中不重复已完成的子任务（携带上下文）
- 迁移日志仅记录元数据，不记录任务内容原文
- Level 3 人工兜底时，交付内容要排版清晰，标注原因
- 不因迁移改变用户原始意图
